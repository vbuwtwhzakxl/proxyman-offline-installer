# Proxyman — Free Offline Installer

![Category](https://img.shields.io/badge/HTTP_Debugger-blue?style=flat-square)

## About

Proxyman is a native macOS HTTP and HTTPS debugging proxy with a beautiful interface. Intercept, inspect, and modify HTTP/HTTPS traffic from iOS devices, simulators, and macOS applications. Features SSL pinning bypass, breakpoints for request/response modification, and a scripting engine for custom logic. Essential for iOS and macOS developers debugging network communication.

## Common Problems & Limitations

- **macOS Primary** — Best macOS experience; Windows version available but less feature-rich
- **Commercial License** — Paid license for full functionality
- **iOS Setup** — Intercepting iOS device traffic requires certificate installation setup
- **SSL Complexity** — SSL inspection requires certificate trust configuration per application
